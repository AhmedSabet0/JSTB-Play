          How editing in Drive works
          
            
            
          • My answers: change an answer, a question's wording or its section; add a row with a section, a question and an answer; clear an answer to delete it.
            • 
            
          • My jobs: change a job's Status (To apply, Applied, Interview, Offer, Rejected, Skipped) or its note; paste a job's link in a new row to add it.
            • 
            
          • Your CV: on a computer, open the file in Drive, then File information › Manage versions › Upload new version (a PDF with text).
            • 
            
          • Your changes reach the app within a few minutes, or right away with Sync now. Columns you add stay.
